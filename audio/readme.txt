Put the Hellbeat song mp3 files in this folder.
 
Name each file after the song: lowercase, with dashes instead of spaces and symbols.
Examples:
  happy-day-in-hell.mp3
  hell-is-forever.mp3
  loser-baby.mp3
  hell-s-greatest-dad.mp3
 
Optional split tracks:
  happy-day-in-hell-inst.mp3   (instrumental only)
  happy-day-in-hell-voc.mp3    (vocals only)
